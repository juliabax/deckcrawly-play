# Deck Crawly

*Olha o naipe dessa masmorra.*

Dungeon crawler estilo Rogue jogado com um baralho de 52 cartas. Sua vida é o seu deck mais a sua mão: sem cartas, sem ações, fim de jogo.

**Jogue aqui:** https://juliabax.github.io/deckcrawly-play/

Funciona no navegador, com mouse ou toque (inclusive no iPad). A tela "Regras" dentro do jogo explica como jogar. Adicione `?seed=123` ao endereço para repetir a mesma masmorra.

Este repositório contém só os arquivos publicados do jogo (HTML, CSS e JavaScript).
